# 🍁 枫叶指令宏

🚀 **枫叶指令宏——让自动化变得简单！无需编程基础，通过简单指令即可实现自动化操作。**

---

## 第一部分：核心语法规范

---

### 1.1 指令分类

枫叶语言中的指令分为两类：

| 指令类型     | 说明                                    | 示例                                               |
| ------------ | --------------------------------------- | -------------------------------------------------- |
| **执行指令** | 可独立执行，完成具体操作                | `变量\等级,10`、`鼠标移动\100,200`、`延迟\500,800` |
| **条件指令** | **只能**用于 `如果\` 后面，不能独立执行 | `识图\...`、`坐标找色\...`、`比较\...`             |

⚠️ **重要**：条件指令（`识图`、`识图CV`、`坐标找色`、`范围找色`、`比较`）**不能单独写在一行**，必须紧跟在 `如果\` 后面作为条件子句。否则解析器会报告"未知指令"错误。

---

### 1.2 注释规则

- **一行里第一个英文分号 `;` 起到行尾都算注释**，执行时完全忽略。分号前面有没有空格都一样 ——
  `变量\等级,10; 这是注释` 与单独一行的注释等价，`a;b` 只执行 `a`。
- 所以**不要**在参数里用 `;`（包括中文标点混排时的英文分号），它会把后半行整段吃掉。

```
; 这是一条注释，运行时不会运行这一条
变量\等级,10
变量\等级,20          ; 行内注释：只执行到分号之前
```

---

### 1.3 分隔符规则

- **指令分隔符**：指令与参数之间用反斜杠 `\` 分隔。即使没有参数，指令末尾也必须保留 `\`。

```
按键\a\
鼠标\左键单击\
延迟\500,1000\
```

- **参数分隔符**：多个参数之间用英文逗号 `,` 分隔。

```
鼠标移动\777,574\
变量\等级,10\
```

---

### 1.4 变量调用规则

- 使用 `@变量名` 的形式引用已定义的变量值。
- 定义变量时**不加** `@`，引用变量时**必须加** `@`。

```
变量\超时,0\          ; 定义变量（不加 @）
弹窗提示\@超时\        ; 引用变量（加 @）
```

- **数组索引访问**：通过 `@变量名[索引]` 访问数组元素，**索引从 1 开始**。

```
数组\创建,英雄列表, 亚瑟|后羿|妲己
弹窗提示\第一个英雄是 @英雄列表[1]
```

- **拼接表达式**：使用 `@(拼接内容)` 动态拼接变量名，拼接符为 `.`。

```
变量\A1, 111
变量\数字, 1
弹窗提示\@(A.@数字)          ; 输出 111
```

- **变量未定义**：若引用的变量不存在，则返回空值。

---

### 1.5 块结构规则

块结构通过**起始关键字**与**结束关键字**配对实现，支持嵌套。

| 块类型 | 起始关键字  | 结束关键字      | 说明                                            |
| ------ | ----------- | --------------- | ----------------------------------------------- |
| 判断块 | `如果\`     | `结束如果`      | 条件判断，支持 `否则如果\`、`否则`              |
| 循环块 | `循环\`     | `结束循环`      | 重复执行，支持 `终止本层循环\`、`跳过本次循环\` |
| 模块块 | `模块定义\` | `结束模块定义`  | 定义可复用的代码模块                            |

⚠️ **结束关键字是裸词**：`结束如果`、`结束循环`、`结束模块定义` **后面不带反斜杠**
（写成 `结束如果`+反斜杠 `\` 是**匹配不上**的，会报「缺少 '结束如果'，条件块未闭合」）。`否则` 同理，裸词。
只有**带参数的起始行**才需要结尾的 `\`。

- 块结构**必须配对**，缺少结束关键字将触发语法错误。
- 块体内部可包含任意指令（包括嵌套的块）。
- **禁止使用 `{}` 或缩进来表示块范围**，必须使用配对关键字。

```
如果\条件\
    条件成立时执行的指令
否则如果\条件2\
    条件2成立时执行的指令
否则
    所有条件都不成立时执行
结束如果
```

---

### 1.6 循环结构体

循环结构体用于重复执行一段指令序列。**循环结构体支持嵌套**（即循环体内可再包含循环）。

- **结构**：

```
循环\次数[, 计数器变量]\
    ...             ; 循环体内的指令
结束循环
```

- **次数说明**：次数为 `0` 表示**循环 0 次（一次都不执行）**；**无限循环写** `循环\无限\`（`无限` 是字面量，不是数字）。次数支持变量引用，如 `循环\@总人数\`。
- **计数器变量（可选）**：`循环\次数,计数器变量名\`，每次迭代将当前次数（从 1 开始）存入该变量。

- **循环控制指令**（必须独立成行）：
  - `终止本层循环\`：立即退出当前最内层循环
  - `跳过本次循环\`：跳过当前迭代，进入下一次迭代

- **简单示例**：

```
; 左键连点10下
循环\10, 循环次数\
    鼠标\左键单击\
结束循环
```

- **无限循环 + 条件退出**：

```
变量\计数,0\
循环\无限, 循环次数\
    悬浮提示\@计数,0,0,1\
    如果\比较\@计数,大于等于,10,结果\
        终止本层循环\
    否则
        运算\@计数,加,1,计数\
    结束如果
    延迟\1000,1000\
结束循环
```

### 1.7 模块结构体

模块结构体用于封装一段可复用的指令序列，实现代码的模块化。

- **结构**：

```
模块定义\模块名\
    ...                 ; 模块内的指令（可包含任意指令）
结束模块定义
```

- **特性**：
  - 模块内可以调用其他模块，但需注意避免递归调用导致死循环。
  - 模块内可包含循环、判断等任何结构体，但**不能再定义新模块**（模块定义不可嵌套）。
  - 模块调用会同步执行，即调用后等待模块执行完毕才继续后续指令。

- **调用格式**：

```
模块\模块名\            ; 执行已定义的模块
```

- **定时调用格式**：

```
模块定时\模块名,毫秒,模式\      ; 模式：重复、一次、关闭（三个参数都必填）
```
  - ⚠️ `模块定时` 是**主流程内的协作式定时器**，不是独立线程；主流程要进入
    `延迟` 才会检查到期定时器。长时间不调用 `延迟` 的循环/指令会让它不触发。
    需要真正后台常驻，用下面的 `模块线程`。

- **简单示例**：

```
模块定义\登录游戏\
    鼠标移动\500,300\
    鼠标\左键单击\
    延迟\1000,1000\
    按键\Enter\
结束模块定义

模块\登录游戏\       ; 调用模块
```

- **嵌套调用示例**：

```
模块定义\模块B\
    弹窗提示\模块B 被调用\
结束模块定义

模块定义\模块A\
    弹窗提示\模块A 开始执行\
    模块\模块B\               ; 调用模块 B
    弹窗提示\模块A 执行结束\
结束模块定义

模块\模块A\          ; 主程序调用模块 A
```

- **定时调用示例**：

```
模块定义\提醒\
    弹窗提示\时间到！\
结束模块定义

模块定时\提醒,5000,一次\   ; 5秒后弹窗
延迟\10000,10000\          ; 主线程继续执行
```

- **后台线程调用格式**：

```
模块线程\任务名,模块名,模式[,轮间隔]\
```
  - 模式：`一次`、`重复`、`关闭`；省略模式默认 `重复`，轮间隔省略默认 50ms。
  - 任务名全局唯一；同名任务未结束再启动会报错并停止脚本。
  - 变量整表共用：任务与主流程读写同一张表；单条 `变量`/`运算` 是原子的，
    跨多条指令的「先判断再赋值」不是原子的，要用标志位协议。
  - 关闭：`模块线程\任务名,模块名,关闭\`，任务名和模块名都要匹配。

- **后台线程示例**：

```
模块定义\提醒\
    弹窗提示\时间到！\
结束模块定义

模块线程\提醒线程,提醒,重复,5000\   ; 每5秒一次，主流程继续
延迟\10000,10000\                  ; 主流程继续10秒
模块线程\提醒线程,提醒,关闭\        ; 停指定任务
```

### 1.8 条件判断结构

- 以 `如果\` 开头，后跟一个或多个条件指令。
- 条件指令之间可通过 `\与\` 或 `\或\` 连接。
- 如果 指令的条件部分仅支持单一逻辑运算符，\与\ 和 \或\ 不可在同一行混合使用。
- 使用 `否则如果\`、`否则` 处理多分支逻辑。
- 必须以 `结束如果` 结尾。

```
如果\比较\@血量,小于,30,低血量\
    弹窗提示\血量过低！
否则如果\比较\@血量,小于,60,中血量\
    弹窗提示\血量中等
否则
    弹窗提示\血量安全
结束如果
```

- **支持的条件指令**：

| 条件指令   | 用途           | 示例                                              |
| ---------- | -------------- | ------------------------------------------------- |
| `比较`     | 值比较         | `如果\比较\@分数,大于等于,60,是否及格\`           |
| `坐标找色` | 检查单点颜色   | `如果\坐标找色\100,200,0xFF0000,色值\`            |
| `范围找色` | 区域找色       | `如果\范围找色\0,0,100,100,0xFFFFFF,10,结果,X,Y\` |
| `识图`     | 模板匹配       | `如果\识图\0,0,0,0,0.1,<头像>,id,count,x,y\`      |
| `识图CV`   | OpenCV图片匹配 | `如果\识图CV\0,0,0,0,0.15,<logo.bmp>,count,X,Y\`  |

⚠️ **`识图CV` 是 9 段**（区域 4 + 容错 + 图片名 + **数量** + X + Y）。少一段会弹模态框并中止脚本，
无人值守时整条流程就停在那儿 —— 上面这个示例在旧版文档里漏了「数量」那一段，照抄会踩。
每条条件的完整参数见 **2.9 条件指令**。

- **识图模式说明**：
  - `等待出现`：等待模板出现，超时后失败
  - `等待消失`：等待模板消失，超时后失败
  - 省略模式：执行一次，立即返回结果（不等待）

### 1.9 BNF 基本范式

```
<脚本>           ::= { <行> }
<行>             ::= [<指令>] <换行>
<指令>           ::= <指令头> "\" [<参数段>]
<参数段>         ::= <参数> { "," <参数> }
<参数>           ::= <字面量> | <变量引用> | <标记> | <颜色值>
<变量引用>       ::= "@" <变量名> [ "[" <表达式> "]" ] | "@(" <拼接表达式> ")"
<拼接表达式>     ::= <片段> { "." <片段> }
<标记>           ::= "<" <名称> ">"
<颜色值>         ::= "0x" <6位十六进制数>
<字面量>         ::= <数字> | <字符串> | <布尔值>
<换行>           ::= "\n"
<注释>           ::= ";" <任意字符>
```

## 第二部分：功能指令详细参数

---

### 2.0 键盘鼠标操作（最常用）

---

#### 键鼠模式（执行指令）

- **格式**：`键鼠模式\模式[, 串口号]\`
- **功能**：切换后续所有键鼠指令的输入通路。
- **模式**：`系统`（默认）、`驱动`（虚拟驱动）、`硬件, 串口号`（CH9329 硬件）、`AR`
- **示例**：

```
键鼠模式\驱动\
键鼠模式\硬件,COM5\
```

---

#### 延迟（执行指令）

- **格式**：`延迟\毫秒\`（固定）或 `延迟\最小毫秒,最大毫秒\`（区间随机）
- **功能**：随机延迟（两值相等时为精确延迟），拟人化的基础。
- **说明**：**单段写法 2026-11-01 起支持**，等价于「最小=最大」；更早的版本少一段会报「无效索引」。
  定时器（`模块定时`）只在 `延迟` 期间被检查，纯循环不睡是触发不到的。
- **示例**：

```
延迟\800\          ; 固定 800 毫秒（推荐写法）
延迟\500,800\      ; 500~800 毫秒之间随机
延迟\1000,1000\    ; 与单段等价
```

---

#### 按键（执行指令）

- **格式**：`按键\键名[, 延迟最小, 延迟最大]\`
- **功能**：按下并释放一个键（延迟单位毫秒，默认 50-80）。
- **示例**：

```
按键\a\
按键\Enter\
按键\a,30,60\
```

---

#### 按下 / 抬起（执行指令）

- **格式**：`按下\键名\`、`抬起\键名\`
- **功能**：仅按下（不释放）/ 释放一个键，组合键用它拼。
- **示例**：

```
按下\Shift\
按键\a\
抬起\Shift\
```

---

#### 鼠标（执行指令）

- **格式**：`鼠标\动作\` 或 `鼠标\动作,X,Y\`
- **动作**（9 个，写在指令名后面的第一段里）：

  | 动作 | 说明 |
  |---|---|
  | `左键单击` / `右键单击` / `滚轮单击` | 按一下再松开（`滚轮单击` = 中键） |
  | `左键按下` / `左键抬起` | 分开写可以拼拖拽 |
  | `右键按下` / `右键抬起` | 同上 |
  | `滚轮向上` / `滚轮向下` | 滚一格，方向写在动作里 |

- **说明**：带坐标（`鼠标\左键单击,100,200\`）时坐标是**后台**落点，要配合 `开启后台`；
  不带坐标走当前光标。屏幕绝对坐标，左上角是 `0,0`。
- ⚠️ **没有 `鼠标滚轮` 这条指令**（2026-10-25 已拆掉）：写 `鼠标滚轮\向下\` 会报「未知指令」，
  正确写法是 `鼠标\滚轮向下\`。拆开的理由就是原版把方向当字符串比、写错一个字静默不动作。
- **示例**：

```
鼠标\左键单击\
鼠标\左键单击,100,200\
鼠标\滚轮向下\
```

---

#### 鼠标移动 / 相对移动（执行指令）

- **格式**：`鼠标移动\X,Y[, 模式]\`、`相对移动\dx,dy[, 模式]\`
- **模式**：`1`（贝塞尔曲线轨迹）、`mh`（梦幻西游专用）；不写 = 瞬移
- **说明**：`相对移动` 从当前鼠标位置偏移（后台态下基准是「落点」而不是真实光标）。
- **示例**：

```
鼠标移动\500,300\
鼠标移动\500,300,1\
相对移动\10,-20\
```

---

#### 识图移动（执行指令）

- **格式**：`识图移动\X偏移,Y偏移[, 模式]\`
- **功能**：移动到**上一次识图结果**的位置加偏移（配合 `如果\识图` 的 X/Y 输出）。
- **说明**：参数是**偏移量**，不是坐标 —— 别把识图输出的 X/Y 填进来（填了就再挪一倍）。
  识图没找到时基点不更新，会走到上一次的位置。
- **示例**：

```
如果\识图\0,0,0,0,0.1,<头像>,id,数量,X,Y\
    识图移动\0,0\
    鼠标\左键单击\
结束如果
```

### 2.1 辅助指令

---

#### 文本输入（执行指令）

- **格式**：`文本输入\输入内容\`
- **功能**：模拟键盘输入指定文本到当前激活的窗口，支持变量引用。
- **参数**：输入内容【必填】支持纯文本、字符串变量（`@变量名`）
- **示例**：

```
文本输入\枫叶指令宏\
```

#### 开启后台（执行指令）

- **格式**：`开启后台\窗口名,后台模式\`
- **模式**：**0~4**（数字越大越"重"、适用面越广）

  | 模式 | 取图方式 | 备注 |
  |---|---|---|
  | `0` | GetDCEx + BitBlt | 最轻，部分受保护窗口取不到 |
  | `1` | 0 + `WS_EX_LAYERED` | |
  | `2` | PrintWindow | |
  | `3` | 2 + `WS_EX_LAYERED` | |
  | `4` | PrintWindow + `PW_RENDERFULLCONTENT` | **最稳**，优先试这档 |

  旧写法 `1+` / `2+` 仍认（分别等于 1 / 3 的效果）。模式写错会弹「后台识别模式接收到未知参数」并中止脚本。

- **说明**：只记录窗口和模式；真正找窗口、绑定截图方式，都在后面每条指令执行时发生。
- **转后台的指令**：`按键`、`按下`、`抬起`、`鼠标`、`鼠标移动`、`识图移动`、`坐标找色`、`识图`、`识图CV`、`文字识别`。

- **模式管什么**：只影响 `识图` / `文字识别` 从窗口取图的方式；`识图CV`、`坐标找色` 不看这个模式。
- **坐标**：后台模式下 `鼠标`、`鼠标移动` 按窗口内坐标写；`识图` 返回窗口内坐标；`坐标找色` 仍按屏幕坐标写。
- **和 键鼠模式 的关系**：不写 `键鼠模式`（或写 `系统`）时后台键鼠用窗口消息；写 `键鼠模式\AR\` 走 AR 后台；驱动 / 硬件在开了后台后不生效（仍走后台消息）。
- **示例**：

```

```
- **注意**：窗口可以遮挡但不能最小化，黑屏时尝试更换模式；后台模式下 `鼠标` 必须带坐标。

### 2.9 条件指令（只能写在 `如果` 里）

这 5 条**不是执行指令**，只能出现在 `如果\` / `否则如果\` 的条件位；独立成行会报
「未知指令」或「未知条件类型」。同一行可以用 `\与\` 或 `\或\` 连多条，但**两种不能混用**。

---

#### 比较

- **格式**：`比较\左值,比较符,右值,结果变量\`
- **比较符**：`等于`、`不等于`、`大于`、`小于`、`大于等于`、`小于等于`、`字符包含`
- **结果变量**：六个关系运算符接 `1`/`0`；**`字符包含` 例外 —— 接的是「值2」作为连续子串在「值1」里
  出现的次数**（0 = 没有，非 0 = 有），所以它既能当条件也能拿来数次数。
- **示例**：

```
如果\比较\@血量,小于,30,低血量\
    弹窗提示\血量过低！
结束如果
```

---

#### 坐标找色

- **格式**：`坐标找色\X,Y,颜色值,结果变量\` —— **四段缺一不可**
- **要点**：X/Y 是**屏幕绝对坐标**；结果变量接的是**实际取到的颜色值**（不是布尔），条件拿它跟第 3 段比；
  漏写第 4 段会报「无效索引」，错误停在 `如果` 那一行，`否则` 分支也不走。
- **示例**：

```
如果\坐标找色\100,200,0xFF0000,色值\
```

---

#### 范围找色

- **格式**：`范围找色\左上X,左上Y,右下X,右下Y,颜色值,色差,结果变量,找色X,找色Y\`（9 段）
- **要点**：`0,0,0,0` 是**一个点**，不是全屏；色差量级 0~255（不是 0~1）；没找到时 X/Y 是空串，不是 `-1`。
- **示例**：

```
如果\范围找色\0,0,100,100,0xFFFFFF,10,结果,X,Y\
```

---

#### 识图

- **格式**：`识图\左上X,左上Y,右下X,右下Y,容错,<标记名>,结果变量,数量变量,X变量,Y变量[,模式,秒]\`（10 段；带模式要 12 段）
- **要点**：容错 0~1 越大越松；`<标记名>` **必须连尖括号一起写**，是 `抓图`／GUI 抓图存下的名字；
  没找到时结果变量为空串、数量为 0，X/Y 变量**不写**（沿用旧值）；
  `等待出现`／`等待消失` 必须**连秒一起写满 12 段**，只写到模式那段会被静默当成「只识一次」。
- **示例**：

```
如果\识图\0,0,0,0,0.1,<头像>,id,数量,X,Y\
如果\识图\0,0,0,0,0.1,<头像>,id,数量,X,Y,等待出现,5\
```

---

#### 识图CV

- **格式**：`识图CV\左上X,左上Y,右下X,右下Y,容错,<图片名>,数量变量,X变量,Y变量[,模式,秒]\`
  （**9 段**；带模式要 11 段）
- **要点**：前面**没有**结果变量这一段 —— 顺序是「数量、X、Y」，少一段会弹模态框并中止脚本；
  图片名来自当前项目 `ScreenShot` 目录下的 bmp/png；引擎是 OpenCV 模板匹配（纯色模板会报 `E_DEGENERATE`）；
  命中多个时逐点写 `<X变量>1..n` / `<Y变量>1..n`。
- **示例**：

```
如果\识图CV\0,0,100,100,0.1,<a.png>,命中数,命中X,命中Y\
```

## 附录：错误码速查

| 错误描述              | 可能原因                                     |
| --------------------- | -------------------------------------------- |
| `未知指令: xxx`       | 指令头不在关键字清单中；或条件指令被独立执行 |
| `缺少 '结束如果'`     | `如果` 块未闭合                              |
| `缺少 '结束循环'`     | `循环` 块未闭合                              |
| `缺少 '结束模块定义'` | `模块定义` 块未闭合                          |
| `无效索引`            | 参数段少了（最常见：条件/指令少写一段），按提示数第几段 |
| `参数不足`            | 指令参数数量不满足                           |
| `除数不能为零`        | `运算\除` 或 `取余` 除数为0                  |
| `数组不存在`          | 操作的数组未创建                             |
| `索引超出范围`        | 数组索引小于1或大于长度                      |
| `识图数据未找到`      | 抓图数据不存在或标记名错误                   |
| `图像文件不存在`      | 图片文件不在 ScreenShot 目录                 |
